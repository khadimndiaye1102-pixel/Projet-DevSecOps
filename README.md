# Projet DevSecOps

Projet de démonstration mettant en pratique les principes DevSecOps : intégration de la sécurité directement dans le pipeline de développement et de déploiement.

## 🎯 Objectif

Ce projet illustre la mise en place d'un pipeline CI/CD sécurisé pour une application web simple, incluant :
- Scan automatique des secrets et credentials
- Scan des vulnérabilités
- Validation du code à chaque push

## 🛠️ Technologies

- HTML/CSS
- GitHub Actions (CI/CD)
- Gitleaks (détection de secrets)
- Trivy (scan de vulnérabilités)
